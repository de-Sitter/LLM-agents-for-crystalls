# 验证原理、对照实验与最终 1000 个材料

## 1. A–F 验证通过的材料学原理

| 原理ID | 已验证原理 |
|---|---|
| principle_program_002 | 低比例 F 在保留 Si-O 骨架时可通过 Mg 特异的 Mg-F 键价失配缓解降低紧致 Mg-Si-O-F 的亚稳尾；不可无条件迁移到 Ca。 |
| principle_program_003 | PO4/P2O7 中断 V-O-V 氧化还原连接，配合 Li 尺寸适配的紧致堆积，可降低 Li-V-P-O 的亚稳尾；Na 替换后优势显著减弱。 |
| principle_program_004 | PSx 共价单元分配硫化物电荷，且紧致 Li/Na-S 配位保留 Madelung 内聚，可降低 Li/Na-P-S 相对 Li/Na-S 的亚稳尾。 |
| principle_program_005 | 紧致 Mg-N 配位配合 Si-N 共价骨架可在特定对照下降低 Mg-Si-N 亚稳尾；后续证据限制其泛化。 |
| principle_program_007 | A2ZnCl4 精确电荷平衡与 ZnCl4 局域配位，在保留 A-Cl 离子堆积时降低 Li/Na/K 氯锌酸盐亚稳尾。 |
| principle_program_008 | BH4-like B-H 共价电荷分配与紧致 Li/Na-H 堆积协同降低 Li/Na-B-H 亚稳尾。 |
| principle_program_009 | 保留 Si-O 骨架时，Mg/Ca-F 键价缓解可在另一套匹配窗口下降低紧致 Mg/Ca-Si-O-F 亚稳尾。 |
| principle_program_010 | Mg:Al:O=1:2:4 与紧致尖晶石氧子晶格的键价匹配可产生罕见的较低 E-hull 极小值，但不是普遍均值规律。 |
| principle_program_012 | Na/K-P-S 的 P-S 电荷分配规律不能直接迁移到 Na-P-O；PO4 共价本身不足以击败紧致 Na-O 端元。 |
| principle_program_013 | Ca-Si-N 的 Si-N 共价/键价适配不可靠地迁移到 Mg-Si-N；Mg-Si-N 是 Mg 特异的失败边界。 |
| principle_program_014 | 保留 B-O 骨架并有限引入 F 可降低紧致 Mg/Ca-B-O-F 亚稳尾；Ba 尺寸过大导致该机制失效。 |
| principle_program_015 | 固定 Rb/Cd 后，Br 极化率可软化 Cd-卤化物笼并缓解 Rb 空腔应变，使 Rb-Cd-Br 优于 Rb-Cd-Cl；不得扩展为 Cd>Zn 或 Rb>Cs。 |
| principle_program_017 | 精确 A3BN2 配比下，B-N 共价分配氮化物电荷；Li 和有限 Na 有效，K/Rb/Cs 因空腔过度膨胀而失败。 |
| principle_program_019 | 强 Si-O 骨架内聚与紧致 Li/Na 氧空腔键价匹配，使 Li/Na-Si-O 的均值 E-hull 低于匹配 Li/Na-P-O。 |
| principle_program_020 | P-S 电荷分配与紧致 Na-S 配位协同，使致密小胞 Na-P-S 的群体 E-hull 低于 Na-S；SUN 并非 primary 独占。 |
