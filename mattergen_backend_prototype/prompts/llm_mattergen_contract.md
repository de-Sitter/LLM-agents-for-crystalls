# LLM to MatterGen Contract

MatterGen is not a language model. Treat it as an external crystal-structure
generator that accepts compact property and chemistry constraints, then returns
candidate crystal structures for the controller to validate.

## Agent Responsibilities

- X/Y propose the scientific search route and decide whether the template
  generator is too restrictive for the current iteration.
- Z translates the selected material route into a `MatterGenBackendRequest`.
- W audits that request for feasibility, novelty constraints, forbidden
  elements, and whether it matches the X/Y scientific route.
- The controller runs MatterGen, filters structures, writes `input.json`, and
  sends failures back to Z/W. MatterGen output is never trusted as stable until
  the project evaluator scores it.

## W Audit Rules

- Reject if Z emits manual coordinates or a pseudo-Structure instead of a
  MatterGen request.
- Reject if `backend != "mattergen"` or `source != "ml_generator"`.
- Reject if `checkpoint` does not support the requested conditioning.
- Reject if `chemical_system` is missing for a route that names a concrete
  element family.
- Reject if forbidden evaluator-null elements are present unless the controller
  explicitly requested a control.
- Reject if `diffusion_guidance_factor` is absent or zero for a conditioned
  request.
- Reject if `target_count`, `batch_size`, or `num_batches` is too small to
  compensate for filtering failures.
- Reject if `exclude_reduced_formulas` omits known used/SUN/failed formulas
  relevant to the route.
- Treat `target_reduced_formula` as a soft preference unless
  `require_target_reduced_formula=true` is explicitly set. The controller honors
  that hard filter, so use it only when X/Y explicitly prove the route is
  unrepresentable without that exact stoichiometry; after
  `not_target_reduced_formula` or `no_accepted_structures`, relax the hard
  filter or change the chemical system.
- Reject if `template_consistency_audit` is missing any required key:
  `chosen_template`, `template_realizes_motif`,
  `unsupported_motif_substitution`, `mechanism_local_motif`,
  `required_coordination_or_polyhedra`, `why_template_is_faithful`.
- Accept only if the request can produce structures that the controller can
  convert to `pymatgen.Structure.as_dict()` and evaluate blind.

## Controller Feedback Back to Z/W

```json
{
  "mattergen_feedback": {
    "request_id": "iter_001_route_name",
    "raw_structure_count": 64,
    "accepted_count": 0,
    "reject_reasons": {
      "excluded_reduced_formula": 20,
      "outside_chemical_system": 14,
      "structure_validation:too_many_sites": 8
    },
    "required_revision": "Increase oversampling, tighten chemical_system, change checkpoint, or return to X/Y if the selected route is not representable."
  }
}
```
